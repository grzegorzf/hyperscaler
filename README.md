## 🌟 Overview

**Hyperscaler** is an interactive, visual-first cloud infrastructure and FinOps simulator engineered to demystify complex distributed systems concepts through real-time cybernetic visuals.

Experience the tangible differences between **Horizontal Auto-Scaling** (Kubernetes pod replication) and **Vertical Scaling Upgrades** (monolithic SMP hardware tiers) under traffic surges up to 125,000+ requests/sec, complete with edge CDN caching deflection, load balancing, real-world multi-cloud cost modeling, rolling telemetry sparklines, and 99.99% SLO error budget tracking.

- **100% Client-Side Engine**: Zero backend servers required. Pure queuing theory, deterministic state transitions, and high-performance particle physics execute directly in your browser at 60 FPS.
- **☁️ Multi-Cloud FinOps Modeling**: Live cost engine for **AWS**, **GCP**, and **Azure** calculating compute instances, egress CDN bandwidth, and load balancer costs. Features **True Scale-to-Zero** ($0.00 at 0 traffic) and surge multipliers.
- **📊 Multi-Cloud Arbitrage Matrix**: Side-by-side financial comparison modal with delta-vs-cheapest and 1-Year (30%) & 3-Year (45%) committed use discount modeling.
- **🧠 Smart Architect Advisory**: Real-time Senior Architect insight ticker identifying FinOps waste, static monolithic traps, origin cache misses, and active chaos outages.
- **🎯 1-Click Architecture Scenarios**: Instant benchmarking for Steady-State Production, Black Friday Surges, Cache Bypass DDoS, Scale-to-Zero Dormancy, Legacy Monoliths, and Multi-AZ Chaos.
- **📈 Rolling Sparklines & 99.99% SLO Tracker**: Live rolling 24-sample SVG sparklines with real-time error budget consumption meters and burn rate indicators.
- **🌿 Green Cloud ESG Tracker**: Carbon footprint estimation adhering to Cloud Carbon Footprint standards (Scope 2 CO₂e, tree offset equivalents, Eco Score A+ to D).
- **📄 Architecture Spec Exporter**: 1-click generation of comprehensive, downloadable GitHub-flavored Markdown architecture specifications.
- **📱 Fully Responsive & Touch-First**: Ergonomic thumb-zone floating dock, slide-up cybernetic drawer, and direct touch inspection for server pods on mobile devices.

## 📐 Mathematical Model & Queuing Theory

The simulation engine implements deterministic mathematical equations in [`src/lib/simulation/physics.ts`](src/lib/simulation/physics.ts):

### 1. Edge CDN Offloading
$$\lambda_{\text{absorbed}} = \lambda_{\text{traffic}} \times H_{\text{cache}}$$
$$\lambda_{\text{origin}} = \lambda_{\text{traffic}} - \lambda_{\text{absorbed}}$$

### 2. Capacity & Little's Law Utilization
- **Horizontal Cluster Capacity**: $C_{\text{total}} = N_{\text{pods}} \times 3{,}000\text{ req/s}$
- **Vertical Monolith Capacity**: $C_{\text{total}} = 4 \times N_{\text{cores}} \times 850\text{ req/s}$
- **Compute Load Ratio**: $\rho = \frac{\lambda_{\text{origin}}}{C_{\text{total}}}$

### 3. Latency Curves & Queuing Backpressure
When utilization $\rho$ exceeds 85%, response latency degrades gracefully following queuing theory backpressure curves:
- $P_{50} = 10\text{ms} + 2 \times \Delta_{\text{excess}}$
- $P_{95} = 20\text{ms} + 5 \times \Delta_{\text{excess}}$
- $P_{99} = 32\text{ms} + 12 \times \Delta_{\text{excess}}$
- $\text{Error Rate } \% = \min(15\%,\, 0.3 \times \Delta_{\text{excess}})$

### 4. Dynamic Particle Swarm Pool
$$N_{\text{particles}} = \operatorname{round}\left(6 + (\text{mult} - 0.2) \times 28.33\right)$$
- At **0.0x traffic (Scale-to-Zero)**: 0 particles (fully quiescent).
- At **1.0x traffic (Steady-State)**: 22 particles (rhythmic pulse along neon conduits).
- At **2.5x traffic (High Surge)**: 67 particles (accelerated multi-stream flow).
- At **5.0x traffic (Extreme Storm)**: 142 particles (intense velocity trails with motion blur).

### 5. Multi-Cloud Cost Modeling (AWS vs GCP vs Azure)
Operational expenditure is evaluated continuously against live cloud hyperscaler pricing models:
- **Total Monthly Cost**: $C_{\text{monthly}} = C_{\text{compute}} + C_{\text{CDN}} + C_{\text{LB}}$
- **Hourly Burn Rate**: $R_{\text{burn}} = \frac{C_{\text{monthly}}}{732\text{ hours}}$
- **Unit Economics**: $\text{Cost per 1M Reqs} = \frac{C_{\text{monthly}}}{(\lambda_{\text{traffic}} \times 2{,}635{,}200) / 10^{6}}$
- **True Scale-to-Zero**: When $\lambda_{\text{traffic}} = 0$, $C_{\text{monthly}} = \$0.00$.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `v20.0.0` or higher (`v22.x` recommended)
- **pnpm**: `v9.0.0` or higher (`v11.x` recommended)

### 1. Local Development
```bash
git clone https://github.com/grzegorzf/hyperscaler.git
cd hyperscaler
pnpm install
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) in your browser.

### 2. Run Automated Test Suite
```bash
pnpm test
```
All **61 unit tests across 18 suites** execute natively in **~0.9s** with zero external testing dependencies via Node 22 (`node:test`).

### 3. Type Checking
```bash
pnpm typecheck
```

### 4. Production Static Build
```bash
pnpm build
```
Generates a production static bundle in `out/`, ready for immediate hosting on GitHub Pages, Cloudflare Pages, Vercel, or AWS S3.

### 5. Docker Deployment
```bash
./start.sh
# or
docker compose up --build -d
```
Access the simulator at [http://localhost:3000](http://localhost:3000).

### 6. Docker Cleanup & Purge
```bash
./delete.sh
```
Stops containers and removes associated images, volumes, and build cache.

## 🌐 GitHub Pages Deployment

The repository includes an automated GitHub Actions deployment pipeline in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml):

1. Push code to the `main` branch of `https://github.com/grzegorzf/hyperscaler`.
2. In your GitHub repository, navigate to **Settings** → **Pages**.
3. Under **Build and deployment** → **Source**, select **GitHub Actions**.
4. Every push to `main` automatically runs typechecks, runs all 61 tests, compiles the static export, and publishes to **[https://grzegorzf.github.io/hyperscaler](https://grzegorzf.github.io/hyperscaler)**.
5. The included [`next.config.ts`](next.config.ts) dynamically handles GitHub Pages `basePath` resolution.
